# M3 完成说明：异常行为检测

## 检测规则

当前 `DetectionEngine` 使用确定性 evaluator，不依赖 LLM 或外部存储：

- `SuspiciousLoginRule`：成功的密码 SSH 登录、来源被标记为新来源；
- `ScheduledTaskPersistenceRule`：创建计划任务并执行临时目录命令；
- `WebChildProcessRule`：Nginx/Apache 等 Web 进程拉起 Shell 或脚本解释器；
- `InterpreterExecutionRule`：非 Web 父进程启动 Shell、解释器或下载器执行非标准命令；
- `ExternalNetworkConnectionRule`：进程连接非 RFC1918、非 loopback、非 link-local 目的地址。

每条命中都会生成稳定的 `alert-{rule_id}-{event_id}`，并包含：

- `AlertSeverity`；
- 0 到 1 的 `risk_score`；
- 关联 `event_ids`；
- 带置信度和原始事件 ID 的 `Evidence`。

## 设计边界

检测规则只消费标准化 `Event`，不直接读取原始 JSONL，也不执行外部动作。后续 M4 可以直接使用这些告警构建行为链，M6 可以把 `DetectionEngine` 封装成白名单工具。高风险响应仍由后续审批模块控制。

## 验收

测试覆盖可疑 SSH 持久化、Web 子进程、外联行为、正常发布窗口、证据回溯、风险分数、重复运行确定性和规则边界。当前全量测试为 `20 passed`。
