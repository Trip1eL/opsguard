# M5 完成说明：MITRE ATT&CK 知识与映射

## 本地知识子集

`knowledge/attack/techniques.json` 是版本化的项目场景子集，当前覆盖：

- `T1021.004` Remote Services: SSH；
- `T1053.003` Scheduled Task/Job: Cron；
- `T1059.004` Command and Scripting Interpreter: Unix Shell；
- `T1105` Ingress Tool Transfer；
- `T1505.003` Server Software Component: Web Shell；
- `T1071.001` Application Layer Protocol: Web Protocols。

第一版使用本地 JSON，保证测试和演示可重复；后续可替换为完整 ATT&CK STIX 导入，不改变 mapper 接口。

## 映射规则

`AttackTechniqueMapper` 基于标准化事件和证据进行确定性映射：

- 只有可疑密码/新来源 SSH 登录才映射 SSH 技术，避免把正常证书登录当成攻击；
- `crontab` 持久化映射 Cron；
- Shell/解释器进程映射 Unix Shell；
- `curl/wget` 外部下载映射 Ingress Tool Transfer；
- Web 进程拉起解释器映射 Web Shell；
- 80/443 外联映射 Web Protocols。

每个 `TechniqueMapping` 都保留技术名称、关联事件 ID、证据摘要和置信度。`CoverageReport` 计算指定 Technique 集合的映射覆盖率，并列出未覆盖技术，供后续 M7 检测策略生成使用。
