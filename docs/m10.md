# M10：真实模型规划与 LangSmith 可观测性

## 设计目标

M10 在已有确定性安全链路之前增加一个可选的 LLM Planner：

```text
自然语言问题
  -> OpenAI-compatible ModelGateway
  -> InvestigationPlan JSON
  -> Pydantic schema + 参数策略校验
  -> 合并用户显式参数
  -> 固定白名单调查工作流
  -> 检测 / 关联 / ATT&CK / Sigma / 沙箱 / 审批
```

职责边界保持明确：

- LLM 负责理解问题、提出调查目标、关注实体和建议工具顺序；
- Pydantic 拒绝额外字段、非法 ATT&CK 编号、乱序或重复工具；
- Planner 只能生成查询字段，schema 中不存在审批和响应授权；
- 用户显式参数覆盖模型建议，所有参数再次经过服务层 allowlist；
- 异常检测、ATT&CK 证据、规则验证、审批和生命周期仍由代码决定；
- 模型超时、网关失败或连续结构校验失败时，调查自动降级到确定性链路。

## 配置与密钥边界

真实模型默认关闭。启用时使用：

```dotenv
OPSGUARD_LLM_ENABLED=true
CHAT_MODEL_PROVIDER=relay
GPT_MODEL_NAME=gpt-5.5
RELAY_BASE_URL=https://example.invalid
RELAY_API_KEY=...
```

`ModelRuntimeConfig` 从环境变量或 ignored 的 `.env` 加载配置。API Key 字段设置为
`repr=False`，不会出现在配置对象的字符串表示、API 状态接口或前端。公开的
`/api/model/status` 只返回开关、provider、model、tracing 状态和项目名。

测试通过显式构造的 Fake Gateway 运行；`create_app()` 默认保持确定性模式。只有
Uvicorn 导入的全局应用显式调用 `create_app(use_configured_model=True)`，因此 CI
不会读取真实凭证或产生模型费用。真实模型模式下页面加载不会自动执行调查，只有用户
明确提交问题后才会调用模型，避免刷新页面意外消耗 Token。

## 结构化计划

`InvestigationPlan` 包含：

- `objective`：调查目标；
- `filters`：受限事件查询字段；
- `focus_entities`：建议关注的账号、主机、进程或网络实体；
- `requested_technique_ids`：需要关注的 ATT&CK 技术；
- `tool_sequence`：按依赖顺序排列的白名单工具建议；
- `reasoning_summary`：简短、证据中立的规划理由。

模型使用 JSON Object 模式返回内容。首次输出不满足 schema 时，Planner 将脱敏后的
校验错误反馈给模型并允许一次修复；第二次仍失败则触发确定性降级。模型工具序列当前
是可解释的建议，实际执行仍使用完整固定链路，避免模型跳过检测验证或治理步骤。

## LangSmith 监测与隐私

启用配置：

```dotenv
LANGSMITH_TRACING=true
LANGSMITH_ENDPOINT=https://api.smith.langchain.com
LANGSMITH_API_KEY=...
LANGSMITH_PROJECT=opsguard-dev
```

每次规划建立一个 `OpsGuard investigation-plan` 根 Run，OpenAI wrapper 在其下记录
一个模型子 Run。应用保留 Trace ID、Trace URL、provider、model、finish reason、
prompt/completion/total Token、端到端延迟、结构校验次数和降级状态。

LangSmith Client 强制设置 `hide_inputs=True` 和 `hide_outputs=True`。根 Run 也只
提交请求长度、不可逆摘要、响应字段名和运行元数据，不提交：

- 原始调查问题；
- System Prompt；
- 事件、告警或日志正文；
- 模型生成的计划正文；
- API Key、代理配置或其他凭证。

Trace flush、项目查询或 URL 生成属于 best-effort 观测，不得阻断模型计划或确定性
调查。模型调用本身失败时，服务层只暴露异常类型和通用降级原因，不返回上游响应正文。

## 工作台

“Agent 观测”视图展示结构化计划、实际应用参数、建议工具链、模型、调用次数、Token、
延迟、结构校验结果、LangSmith 项目和 Trace 链接。确定性模式和模型降级模式使用同一
视图，便于演示正常路径和故障路径。页面不展示 Prompt、凭证或被隐藏的 Trace 内容。

## 已验证路径

真实中转网关已确认能够列出配置模型并调用 `gpt-5.5` JSON Chat Completions。
LangSmith 已成功查询根 Run 和模型子 Run。泄露检查确认整棵 Trace 不包含原始问题、
System Prompt、计划目标或任一 API Key。桌面和移动工作台均能显示 Trace，且无横向
溢出、按钮裁切、页面异常或控制台错误。
