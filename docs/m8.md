# M8：响应审批与策略生命周期

## 治理链路

```text
Validated rule + behavior evidence
  -> RiskAssessor
  -> ResponsePlanner
  -> human ApprovalDecision
  -> ResponseExecutor (simulation only)
  -> VALIDATED -> CANARY
  -> CanaryMetrics evaluation
       -> ACTIVE
       -> ROLLED_BACK
  -> append-only AuditRecord stream
```

M8 在 Multi-Agent 调查链末端增加 `govern_policy_and_response` 白名单工具。风险评估
与响应提案可以自动完成，但响应执行、规则灰度和正式激活均由确定性代码门禁控制，
Agent 无权绕过。

## 风险分级

`RiskAssessor` 以最高告警风险分数为基础，并记录可解释的加权因素：

- Web 服务拉起命令解释器；
- 计划任务持久化；
- 行为链跨越至少三个攻击阶段。

风险被划分为 `low`、`medium`、`high`、`critical`。项目中的 SSH 入侵链
被判为高风险，Web Shell 链被判为严重风险。评分、等级和命中因素一并进入报告和审计。

## 响应提案与审批

高风险或严重行为可以生成以下模拟动作：

- 隔离关联主机；
- 禁用关联账号；
- 阻断行为链中的外部域名。

`ApprovalDecision` 必须包含审批 ID、调查 `scope_id`、审批人、决定、原因和带时区
的时间。缺少审批时报告状态为 `awaiting_approval`；拒绝或作用域不匹配时，规则
保持 `VALIDATED`，模拟响应状态不发生变化。

当前本地原型把结构化 `ApprovalDecision` 视为可信应用边界传入的数据，而不是从
模型自然语言中提取审批。M9 的 API/UI 必须在认证人工操作后构造该对象；当前对象
本身不构成数字签名，也不能直接作为生产授权凭证。

即使动作是本地模拟，仍执行完整审批门禁。当前 `ResponseSimulator` 只修改进程内
`SandboxState`，不会隔离真实主机、禁用真实账号或修改真实网络策略。

## 规则生命周期

允许的状态转换为：

```text
DRAFT -> VALIDATED        # M7 离线验证通过
VALIDATED -> CANARY       # 同作用域人工审批通过
CANARY -> ACTIVE          # 灰度指标通过
CANARY -> ROLLED_BACK     # 灰度指标越界
ACTIVE -> ROLLED_BACK     # 人工回滚
```

不存在 `DRAFT -> CANARY`、`VALIDATED -> ACTIVE` 等越级路径。状态转换返回新的
`DetectionRule` 副本，不原地覆盖此前版本。

## 灰度与自动回滚

`CanaryMetrics` 包含评估事件数、误报率、错误率和 P95 延迟。默认门槛为：

```text
evaluated_events >= 1
false_positive_rate <= 0.05
error_rate <= 0.01
p95_latency_ms <= 200
```

审批通过但没有灰度指标时，规则只停留在 `CANARY`。任一指标越界时系统记录全部
breach，并自动转换为 `ROLLED_BACK`；全部通过才进入 `ACTIVE`。门槛可通过
`CanaryPolicy` 注入。

## 审计

每次治理过程都会记录：

- 风险评估和响应提案；
- 等待审批、审批通过或审批拒绝；
- 被阻止的响应或规则转换；
- 每个模拟响应动作；
- 规则转换前后状态；
- 灰度指标、健康结论和越界原因；
- 自动或人工回滚。

`InMemoryAuditLog` 是追加式本地 adapter，对外只返回深拷贝。M9 可以在不改变治理
接口的情况下替换为数据库或事件流持久化。

## Agent 调用参数

```python
InvestigationRequest(
    "调查新来源 SSH 登录后的可疑行为",
    parameters={
        "approval": {
            "approval_id": "approval-ssh-001",
            "scope_id": "case-for-alert-suspicious_login-evt-ssh-001",
            "actor": "soc-lead",
            "approved": True,
            "reason": "evidence and validation reviewed",
            "created_at": "2026-09-12T10:00:00+08:00",
        },
        "canary_metrics": {
            "evaluated_events": 1000,
            "false_positive_rate": 0.01,
            "error_rate": 0.001,
            "p95_latency_ms": 30,
        },
    },
)
```

不传 `approval` 是正常且安全的默认用法：调查仍会返回风险、建议、规则和完整证据，
但不会执行响应或发布规则。
