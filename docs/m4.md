# M4 完成说明：行为关联与图谱

## 关联逻辑

`BehaviorCorrelator` 以检测告警中的事件为锚点，在可配置时间窗口内按主机、用户和网络实体扩展相关事件，并按时间排序生成 `BehaviorChain`。当前行为阶段映射包括：

- SSH/HTTP 请求 -> `initial_access`；
- 进程启动 -> `execution`；
- 计划任务创建 -> `persistence`；
- 外部网络连接 -> `command_and_control`。

关联器同时生成 `BehaviorGraph`：

- 事件、主机、用户、进程、文件、IP 和域名作为节点；
- 事件与实体之间建立 `OBSERVED_ON`、`PERFORMED_BY`、`EXECUTED_PROCESS` 等关系；
- 按行为顺序建立 `LEADS_TO` 因果边；
- 根据父进程字段建立 `SPAWNED` 进程边。

## 图存储边界

- `InMemoryBehaviorGraph` 用于单元测试和本地演示，支持节点 upsert、边去重和关系查询；
- `Neo4jBehaviorGraphAdapter` 不强制安装 Neo4j Python 客户端，支持生成参数化 Cypher，并通过注入 driver 执行 upsert/query；
- 上层关联器只依赖 `BehaviorGraph`，后续接 Docker Neo4j 不需要改动行为分析逻辑。

## 验收

当前测试覆盖 SSH 持久化链、Web 子进程链、实体关系查询、缺失锚点错误、父子进程边和 Neo4j Cypher 生成；全量测试为 `24 passed`。
