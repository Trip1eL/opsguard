# M2 完成说明：日志归一化与检索

## 归一化

`EventNormalizer` 根据 `EventSource` 将 Linux audit、Web access 和 process/network payload 分发到 source-specific parser，统一产出 `Event`。未知 source、缺少必需字段或 source 与 parser 不匹配时抛出 `EventNormalizationError`。

## Repository

`EventRepository` 是后续替换 Elasticsearch/OpenSearch 的协议，当前提供：

- `InMemoryEventRepository`：按 `event_id` 幂等写入，拒绝同 ID 不同内容的冲突事件；
- `JsonlEventRepository`：读取 JSONL 或 M1 `DatasetRecord`，先归一化再建立索引。

`EventQuery` 支持：

- 时间范围；
- event ID 集合；
- source、host、user、process；
- source/destination IP、domain 和 action。

查询结果按 `(timestamp, event_id)` 稳定排序，保留 `event_id` 和 `raw_log`，便于后续告警证据引用。

## 验收

当前 M2 集成测试覆盖 3 个 fixture、9 条事件、跨 source 查询、实体和时间过滤、重复 ID 冲突、未知 source 和非法时间范围。后续接入 OpenSearch 时只需实现同一 `EventRepository` 协议，不改变上层检测和 Agent 调用契约。
